Contributing

Thanks for contributing to Awesome Learning Resources! ❤️

This project is community-maintained, and useful contributions are welcome.

How to contribute

1. Fork this repository.
2. Add a useful free learning resource.
3. Put it in the correct category.
4. Include the resource name, official URL, and a short description.
5. Check that the link works.
6. Submit a Pull Request.

You can contribute by

- Adding courses
- Adding educational websites
- Adding free books or documentation
- Adding practice resources
- Fixing broken links
- Improving descriptions
- Adding new categories
- Improving documentation
- Fixing spelling or formatting

Please don't submit

- Spam
- Scam or malicious websites
- Pirated content
- Duplicate entries
- Misleading information
- Broken or unrelated links
- Affiliate links

Pull Requests

Keep your Pull Request focused and clearly explain what you changed.

Thanks for helping improve the project! 🚀
